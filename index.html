🔥 Firebase 即時同步設定
填入你的 Firebase 專案設定，即可讓所有人即時共用同一份資料，輸入的瞬間其他裝置立刻看到更新。
📋 設定步驟：
1. 前往 console.firebase.google.com 建立專案
2. 左側選「Realtime Database」→「建立資料庫」→選「測試模式」
3. 點右上角「齒輪」→「專案設定」→拉到「您的應用程式」區塊
4. 點「</>」新增網頁應用程式，複製 firebaseConfig 的各欄位填入下方
❌ Firebase SDK 尚未載入。請確認你有網路連線，或將此 HTML 上傳到 GitHub Pages / 網頁空間後再開啟。
⚠️ 安全提醒：Realtime Database 規則請設為「測試模式」或限制只有特定 IP/網域可讀寫，避免公開洩漏。
若要限制存取，可在 Firebase Console → Realtime Database → 規則 貼入：
{"rules":{".read":true,".write":true}}（測試用，正式使用請加 auth 限制）
